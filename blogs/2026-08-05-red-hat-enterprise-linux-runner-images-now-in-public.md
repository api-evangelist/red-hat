Red Hat and GitHub have published Red Hat Enterprise Linux (RHEL) runner images for both RHEL 9 and RHEL 10 for GitHub Actions. They are available today as GitHub-hosted larger runners in public preview.Public preview means this feature is real, fully documented, and ready for technical testing. During this phase, the runner images do not include formal GitHub SLAs or technical support obligations.
