# Red Hat

> APIs and developer resources from Red Hat, a leading provider of enterprise open source solutions spanning Linux (RHEL), Kubernetes/containers (OpenShift), automation (Ansible), identity (Keycloak), and the Hybrid Cloud Console (console.redhat.com). This is an API Evangelist catalog profile; it links Red Hat's own documentation and the machine-readable artifacts curated in this repository. Generated from apis.yml — no fabricated endpoints.

## APIs

- [Red Hat OpenShift Cluster Manager API](https://api.openshift.com/): Provision, manage, and monitor OpenShift clusters across clouds.
- [Red Hat OpenShift API](https://docs.openshift.com/container-platform/latest/rest_api/index.html): Manage OpenShift clusters, applications, and resources.
- [Red Hat Ansible Automation Platform API](https://docs.ansible.com/automation-controller/latest/html/controllerapi/api_ref.html): Automate infrastructure, deployment, and configuration via the automation controller.
- [Red Hat build of Keycloak Admin REST API](https://docs.redhat.com/en/documentation/red_hat_build_of_keycloak/26.0/html/server_developer_guide/admin_rest_api): Manage realms, users, clients, roles, and identity federation.
- [Red Hat Quay API](https://docs.redhat.com/en/documentation/red_hat_quay/): Container registry — repositories, tags, robot accounts, image scanning.
- [Red Hat Insights API](https://console.redhat.com/docs/api): Predictive analytics and remediation across RHEL fleets.
- [Red Hat Satellite API](https://docs.redhat.com/en/documentation/red_hat_satellite/6.16/html-single/using_the_satellite_rest_api/index): Content, provisioning, and patch management for Linux estates.
- [Red Hat Security Data API](https://docs.redhat.com/en/documentation/red_hat_security_data_api/1.0/html-single/red_hat_security_data_api/index): CVE, CSAF, and OVAL security data.
- [Red Hat API Catalog](https://developers.redhat.com/api-catalog): The full catalog of Hybrid Cloud Console service APIs (cost management, image builder, vulnerability, compliance, RBAC, notifications, and more).
